# 🌐 Team Portfolio Website

This project is a group portfolio website developed as part of a Multimedia course final project. It showcases team members, project information, and design concepts using modern front-end web technologies.

---

## 📌 Project Overview

The website is designed to present a clean and interactive portfolio interface, allowing users to explore team member profiles, project details, and overall design work. It focuses on visual presentation, layout structure, and user-friendly navigation.

---

## 🚀 Features

* Responsive and clean UI design
* Navigation between multiple sections/pages
* Team member introduction section
* Project showcase layout
* Smooth user experience with simple interactions

---

## 🛠️ Technologies Used

* **HTML5** – Structure of the website
* **CSS3** – Styling and layout design
* **JavaScript** – Basic interactivity and dynamic elements
